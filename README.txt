Set List PWA v1.25

Category assignment improvement:
- Long-press a Saved Set name: after entering the name, Category is selected from a visible list.
- The list contains all existing Saved Sets categories plus “New category…”.
- “New category…” creates and assigns a category immediately.
- Repertoire song editing now uses the same category picker: existing Repertoire categories plus “New category…”.
- Repertoire and Saved Sets category systems remain completely independent.
- All v1.24 functionality and data remain compatible.
- Caching remains disabled during development.
