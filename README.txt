SET LIST PWA

Это полноценный тестовый пакет для размещения на HTTPS-хостинге.

Важно:
- Встроенный просмотрщик файлов ChatGPT может не выполнять JavaScript.
- Поэтому вкладки и интерактивность нужно тестировать в обычном браузере после публикации.
- Время песни теперь вводится двумя отдельными полями: минуты и секунды.
- 12 песен MessAge уже включены.
- Данные сохраняются через localStorage.
