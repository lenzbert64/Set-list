Set List PWA v1.24

Three requested additions:

1. Categories
- Repertoire categories are now user-defined.
- Repertoire filter contains “New category…” for creating categories.
- Add Song and Add songs as a list use the same dynamic category list.
- Editing a song can assign an existing or new category.
- Saved Sets now have their own category filter with “New category…”.
- Existing saved sets migrate to “Uncategorized”.
- Save Current Set includes a category selector.
- Press-and-hold editing of a Saved Set can also change its category.

2. Saved Sets Undo
- One-level “Undo last change” is placed between Saved Sets and Backup / Restore.
- Covers Save/overwrite, Duplicate, Delete, Rename/category edit, and Saved Sets category creation.
- No Redo.

3. Saved Set rename
- Press and hold the saved set name to rename it.
- Tap still opens the saved set normally.

Additional cleanup:
- Remaining user-facing Russian interface strings were translated to English.
- Backup format v3 includes both category lists, saved-set categories, and Current Set name.
- Older backups remain compatible.
- Caching remains disabled during development.
