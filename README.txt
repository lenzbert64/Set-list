Set List PWA v1.48

Repertoire swipe-to-delete:
- Swipe a Repertoire song row to the right.
- A red Delete button appears on the left.
- Tap Delete, then confirm.
- Confirmed deletion removes the song from Repertoire, Current Set and all Saved Sets.
- Tapping an open row closes it.
- Opening another row closes the previous one.
- Delete has been removed from the song edit/category flow.
- All other v1.47 behavior is unchanged.
